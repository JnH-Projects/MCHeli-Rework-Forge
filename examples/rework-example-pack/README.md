# MCHeli Rework example pack

A content pack with one vehicle, the **Rework Scout**, a two seat light helicopter with two paint
schemes. Everything in it was made for MCHeli Rework (none of it comes from the original 1.0.3
content), and it is meant as the starting point for your own pack.

To try it, copy this folder (or a zip of it) into `<game dir>/mcheli/packs` and start the game, or
run `/mcheli reload` in a world. The Scout appears in the MCHeli Helicopters creative tab.

How packs work, and what each file does: [docs/content/packs.md](../../docs/content/packs.md).
